# Constructors in C++ — Revision Notes

> Ye notes tumhare `Customer` class wale code pe based hain — Constructor, uske types (Default, Parameterized), Constructor Overloading, aur `this` pointer sab cover hai.

---

## 1. Constructor kya hota hai?

**Definition:** Constructor ek **special member function** hota hai jo **class ke naam jaisa hi hota hai**, jiska **koi return type nahi hota** (na `void` bhi nahi), aur jo **object banate hi automatically call** ho jaata hai — object ko **initialize (setup)** karne ke liye.

**Analogy:** Constructor bilkul aisa hai jaise koi **naya ghar banate hi usme basic cheezein (bijli, paani connection) automatically set ho jaana** — tumhe alag se switch on karne ki zaroorat nahi padti, ghar (object) banate hi wo setup ho jaata hai.

```cpp
class Customer {
    string name;
public:
    Customer() {                      // <- ye constructor hai
        cout << "Object bana!";
    }
};

Customer c1;   // Customer() automatically call ho gaya, "Object bana!" print hoga
```

### Constructor Ki Pehchaan (Rules)

1. Constructor ka naam **class ke naam jaisa** hona chahiye (`Customer` class → `Customer()` constructor).
2. Constructor ka **koi return type nahi hota** (`void` bhi nahi likhte).
3. Jab bhi `new ClassName()` ya `ClassName obj;` likhte ho, constructor **automatically call** ho jaata hai — tumhe khud call karne ki zaroorat nahi.

## 2. Default Constructor

**Definition:** Wo constructor jo **koi parameter/argument nahi leta**. Agar tum khud koi constructor nahi likhte, to C++ khud-ba-khud ek **empty default constructor** bana deta hai (compiler-generated). Lekin agar tum khud likhna chaho (jaise tumhare code mein), to fixed values bhi de sakte ho.

```cpp
Customer()
{
    cout << "Hello I am Default Constructer\n";
    name = "Yash";
    account_number = 827363;
    balance = 2132;
}
```

**Kaise call hota hai:**

```cpp
Customer *A1 = new Customer();   // ya sirf: Customer c1;
// Output: "Hello I am Default Constructer"
// A1 ke andar name="Yash", account_number=827363, balance=2132 automatically set ho gaya
```

**Analogy:** Ye aisा hai jaise koi phone **factory-default settings** ke saath aata hai — tum kuch set nahi karte, phir bhi usme kuch default wallpaper, ringtone already set hoti hai.

---

## 3. Parameterized Constructor

**Definition:** Wo constructor jo **parameters (arguments) leta hai**, taaki object banate hi **custom values** se initialize ho sake — default fixed values ki jagah.

```cpp
Customer(string name, int account_number, int balance) {
    this->name = name;
    this->account_number = account_number;
    this->balance = balance;
}
```

**Kaise call hota hai:**

```cpp
Customer *A2 = new Customer("Honey Singh", 1, 12345);
// name = "Honey Singh", account_number = 1, balance = 12345 — tumhare diye hue values se set ho gaya
```

**Analogy:** Ye aisa hai jaise phone **buy karte waqt hi customize karke lena** — apna naam, apni language, apni settings pehle se select karke.

## 4. `this` Pointer — Sabse Important Concept

**Definition:**`this` ek **implicit (automatic) pointer** hota hai jo **har non-static member function ke andar available** hota hai, aur wo **current object ka address** store karta hai — matlab jis object pe function call hua hai, `this` uski taraf point karta hai.

### Kyu Zaroori Hai `this`?

Jab constructor ke parameter ka naam aur class ke data member ka naam **same** ho (jaise dono `name`), to compiler confuse ho jaata hai ki `name = name;` likhne pe kaunsa `name` kaunsa hai. `this->name` likhne se clear ho jaata hai ki **left wala `this->name` class ka member hai**, aur **right wala `name` parameter hai**.

```cpp
Customer(string name, int account_number, int balance) {
    this->name = name;
    //   ↑            ↑
    //  class ka     parameter wala
    //  member       (jo function ko diya gaya)
}
```

**Agar `this->` na likhte:**

```cpp
Customer(string name, ...) {
    name = name;   // GALAT! Ye sirf parameter ko khud ke barabar rakh raha hai
                    // class ke member `name` mein kuch set hi nahi hoga (garbage value rahegi)
}
```

**Analogy:** Socho class ke andar ek "name" naam ka locker hai, aur function ko bhi ek parcel mila hai jiska naam bhi "name" hai. Agar tum sirf bologe "name ko name mein rakh do" to confusion hoga — konsa konsa? `this->name` bolna matlab hai **"is (this) locker mein parcel wala name rakh do"** — crystal clear ho jaata hai.

**Extra Tip:** Agar parameter ka naam alag rakh do (jaise tumhare doosre constructor mein `a`, `b` use kiya), to `this->` ki zaroorat nahi padti kyunki naam clash hi nahi ho raha:

```cpp
Customer(string a, int b) {
    name = a;              // koi confusion nahi, alag naam hai isliye this-> zaroori nahi
    account_number = b;
}
```

## 5. Constructor Overloading

**Definition:** Jab ek hi class mein **multiple constructors** likhe jaate hain, lekin unke **parameters (number ya type) alag-alag** hote hain — isse **Constructor Overloading** kehte hain. Ye **Function Overloading** ka hi ek type hai.

**Analogy:** Ye aisa hai jaise ek hi restaurant mein "Pizza order karne" ke multiple tareeke hon:

* Sirf "Pizza do" bolo → **default pizza** milega (default constructor)
* "Margherita Pizza, medium size, extra cheese ke saath do" bolo → **fully customized** (3-parameter constructor)
* "Farmhouse Pizza, medium size do" bolo → **partially customized** (2-parameter constructor)

Restaurant (class) samajh jaata hai ki tumne **kitni details di hain**, uske hisaab se sahi method (constructor) khud-ba-khud choose ho jaata hai.

```cpp
class Customer {
public:
    Customer() { ... }                                          // 0 parameters
    Customer(string name, int account_number, int balance) { ... }  // 3 parameters
    Customer(string a, int b) { ... }                            // 2 parameters
};
```

Compiler **kitne aur kaunse type ke arguments diye gaye hain**, usse dekh kar decide karta hai ki **kaunsa constructor call karna hai**:

```cpp
Customer *A1 = new Customer();                    // 0 args    -> Default Constructor call hoga
Customer *A2 = new Customer("Honey Singh",1,12345);// 3 args    -> Parameterized(3) Constructor call hoga
Customer *A3 = new Customer("Mohit",2);            // 2 args    -> Overloaded(2) Constructor call hoga
```

**Rule:** Overloaded constructors ke parameters ka **number ya type different** hona chahiye, warna compiler confuse ho jaayega (ambiguous call error dega).

## 6. Tumhare Poore Code Ka Flow

```cpp
Customer *A1 = new Customer();                     // Default Constructor -> Yash, 827363, 2132
Customer *A2 = new Customer("Honey Singh",1,12345); // 3-param Constructor -> Honey Singh, 1, 12345
Customer *A3 = new Customer("Mohit",2);             // 2-param Constructor -> Mohit, 2, (balance uninitialized/garbage)

A1->display();   // Yash->827363->2132
A2->display();   // Honey Singh->1->12345
A3->display();   // Mohit->2->[garbage value, kyunki balance kabhi set nahi hua is constructor mein]
```

> ⚠️ **Dhyan do:**`A3` wale constructor mein `balance` set nahi kiya gaya — isliye `A3->display()` mein `balance` ki value **garbage (undefined)** aa sakti hai. Achi practice hai ki har constructor mein **saare members ko kisi na kisi value se initialize** karo (chahe default `0` hi sahi).

## 7. Pointer Wala Note (`A1->display()` kyu, `A1.display()` kyu nahi)

```cpp
Customer *A1 = new Customer();
A1->display();     // sahi — kyunki A1 ek POINTER hai
// A1.display();    // GALAT — '.' sirf normal object pe chalta hai, pointer pe nahi
```

Jaisa pichle notes mein bataya — `A1`**stack pe** hai aur ek **address store** karta hai (jo heap pe bane object ka hai). `->` operator use hota hai jab tumhare paas **pointer** ho; `.` operator use hota hai jab tumhare paas **direct object** ho.

```cpp
Customer c1;           // normal object -> c1.display() use hoga
Customer *A1 = new Customer();  // pointer -> A1->display() use hoga
```

---

## 8. Quick Recap (Interview-Ready)

* **Constructor** = class jaisa naam, no return type, object banate hi **auto-call** hota hai.
* **Default Constructor** = 0 parameters leta hai, fixed/default values set kar sakta hai.
* **Parameterized Constructor** = parameters leta hai, custom values se object initialize karta hai.
* **`this` pointer** = current object ka address; jab parameter aur member ka naam same ho tab confusion door karne ke liye use hota hai (`this->name = name;`).
* **Constructor Overloading** = same class mein multiple constructors, alag-alag parameters ke saath — compiler arguments dekh ke sahi wala khud choose karta hai.
* Pointer se object ke members access karne ke liye `->` use hota hai, direct object ke liye `.`.
